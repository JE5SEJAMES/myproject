Current Status

Products

The different web browswer products available today include:

  • Chrome
  • Safari
  • Edge
  • Firefox
  • Samsung Internet
  • Opera
  • Brave
  • Android Browser
  • UC Browser
  • Other, more niche browsers
Note that web browsers are not only used on desktop computers, but also on mobile devices such as smartphones and tablets.

People

The main people involved with browser products are mainly the leadership of the companies that dominate the browser market:

  • Google Chrome/Chromium: Sundar Pichai and Chris Cox
  • Apple Safari: Tim Cook
  • Microsoft Edge: Satya Nadella
  • Mozilla Firefox: Mitchell Baker
  • Samsung Browser: Jinho Kim

Organizations

The main organizations involved with web browsers are not limited to the creators, but also standards organizations:

  • W3C – sets web standards and recommendations
  • ECMAScript Language Consortium (TC39) – sets JavaScript standards
  • WHATWG – sets HTML and DOM standards
  • Khronos Group – standardizes graphics/web technologies
